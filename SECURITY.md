# Security

This repository is maintained by [nmdl-mizo](https://github.com/nmdl-mizo) and is **not** affiliated
with Microsoft. Please do **not** report issues in this repository to the Microsoft Security
Response Center (MSRC).

If you believe you have found a security vulnerability in this repository, please do not disclose
it in a public issue. Instead, report it privately via GitHub's
[Report a vulnerability](https://github.com/nmdl-mizo/mattergen-e-/security/advisories/new) form.

If the vulnerability originates in the upstream code, please also consider reporting it to the
upstream [microsoft/mattergen](https://github.com/microsoft/mattergen) project by following its
[security policy](https://github.com/microsoft/mattergen/blob/main/SECURITY.md).
