# Contributing

Contributions and suggestions are welcome — please open an issue or a pull request at
[nmdl-mizo/mattergen-e-](https://github.com/nmdl-mizo/mattergen-e-).

By submitting a contribution, you agree that it is your own work (or that you have the right
to submit it) and that it will be released under the [MIT License](LICENSE) of this repository.
No Contributor License Agreement (CLA) is required.

Note that this repository is not affiliated with Microsoft; the contribution process of the
upstream [microsoft/mattergen](https://github.com/microsoft/mattergen/blob/main/CONTRIBUTING.md)
repository (including the Microsoft CLA) does not apply here.
